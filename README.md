## 🚀 Быстрый старт

### Совместимость с обновлённым порталом (3.0.2)

Плеер Plyr, прежний стиль выбора, верхние кнопки, пресеты и горячие клавиши работают в обоих режимах. Старые ролики сохраняют четыре категории; новый тип показывает один вопрос с ответами «Читер / Неясно / Не читер». Пресеты этих режимов хранятся отдельно. Интерфейс и журнал клипов переведены на русский. В новом режиме сохраняются исходное видео, ограничения просмотра и подтверждение сайта; момент решения передаётся без изменений.

История сохраняет общий ответ и `verdict_tick` после открытия следующего задания в той же вкладке. До перехода запись хранится временно 10 минут; если следующего задания нет, запись ещё не попадёт в историю. Старые клипы с четырьмя категориями используют прежний интерфейс. Совместимость проверена на сохранённой странице и локальных сценариях; отправка на сервер в авторизованной сессии требует проверки в браузере.

> Нужен действующий доступ к официальному порталу разметки VACNet.

1. Скачайте архив для своего браузера на странице [Releases](https://github.com/MartinDawgor/VacNet-Toolkit-Extension/releases).
2. Распакуйте архив в отдельную папку.
3. Откройте `chrome://extensions`, включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**.
4. Выберите распакованную папку и откройте портал VACNet.

<details>
<summary><b>Установка в Firefox</b></summary>

1. Используйте Firefox 128 или новее и скачайте Firefox-сборку.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **Загрузить временное дополнение** и выберите `manifest.json` из распакованной сборки.

Временное дополнение потребуется загрузить повторно после перезапуска Firefox. Для постоянной установки нужен подписанный пакет.
</details>

## Разработка

Для сборки из исходников нужны Node.js 22.12 или новее и npm.

```sh
npm ci
npm run check
```

`check` проверяет TypeScript, собирает расширение для Chrome и Firefox и проверяет содержимое обеих сборок: разрешения, скрипты, ресурсы и переводы.

После добавления или удаления ключей в `public/_locales` выполните `npm run generate:i18n`, чтобы обновить типизированный список переводов.

| Команда | Результат |
| --- | --- |
| `npm run dev` | Разработка в Chrome с автоматической перезагрузкой |
| `npm run dev:firefox` | Разработка в Firefox |
| `npm run build:all` | Обе сборки в `.output/chrome-mv3` и `.output/firefox-mv3` |
| `npm run typecheck` | Проверка типов без сборки |
| `npm run zip` | Архив для Chrome в `.output` |
| `npm run zip:firefox` | Архив для Firefox в `.output` |

Для ручной установки выбирайте папку соответствующей сборки, а не корень репозитория. Firefox-сборка использует отдельный локальный ID `vacnet-toolkit-local@extensions.invalid`; её настройки и история хранятся отдельно от опубликованного дополнения. При необходимости перенесите историю через экспорт и импорт. Локальный архив Firefox не подписан.

## ✨ Главное

- **Современный плеер → удобный анализ.** Скорость от 0.25× до 4×, точная перемотка, шаг по кадрам, 2× масштаб, сохранение громкости и маркер события.
- **Пресеты → четыре ответа одним действием.** Создайте до девяти цветных пресетов, назначьте вердикты и при необходимости включите мгновенную отправку для конкретного пресета.
- **Быстрый переход → меньше ожидания.** После принятия вердикта следующий клип обычно загружается без полной перезагрузки страницы.
- **Повторы → меньше двойной работы.** Расширение находит ранее встречавшиеся фрагменты, показывает прошлые ответы и может подставить их для проверки.
- **История → контекст всегда под рукой.** До 1000 отправленных заданий хранятся локально, группируются по матчам и доступны для импорта или экспорта в JSON.
- **Светлая и тёмная темы → комфорт в любом окружении.** Тема применяется и к порталу, и к интерфейсу расширения.
- **Русский и английский → знакомый интерфейс.** Язык выбирается по языку браузера, а известные элементы портала переводятся автоматически.

## 🎮 Плеер и вердикты

Подозрительный момент отмечается на шкале времени. Перед событием появляется обратный отсчёт, а точная подсказка прогресса помогает быстро изучить короткий фрагмент.

Панель вердиктов содержит четыре категории: **Aim Assist**, **Wall Hack**, **Auto BHop** и **Bot**. Для каждой доступны варианты **Да**, **Не уверен** и **Нет**.

Дополнительно можно:

- закрепить элементы управления плеером;
- растянуть видео под доступную область;
- скрыть видимый ник проверяющего;
- копировать гостевую ссылку на клип;
- открыть метрики текущего задания;
- импортировать, экспортировать или очистить локальную историю.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `1`–`9` | Применить пресет по позиции |
| `Пробел` | Воспроизведение / пауза |
| `R` | Вернуться к началу рабочего диапазона |
| `E` | Перейти к моменту перед подозрительным событием |
| `←` / `→` | Шаг назад / вперёд |
| `[` / `]` | Уменьшить / увеличить скорость |
| `Z` | Включить / выключить 2× масштаб |
| `Enter` | Отправить текущий вердикт |
| `Backspace` | Пропустить клип |
| `Esc` | Закрыть открытую панель или диалог |

Клавиши привязаны к физическому расположению и работают с разными раскладками. Они отключаются при вводе текста, работе с элементами управления, открытом диалоге и во время отправки.

В новом режиме `Enter` подтверждает выбранный ответ после штатной задержки сайта; `Backspace` выбирает «Неясно», когда этот ответ доступен. `E` работает только у роликов с отмеченным подозрительным событием.

> Если для пресета включена опция **«Сразу отправлять»**, нажатие соответствующей цифры отправит сохранённый ответ. В новом режиме сохраняются блокировка ответов до просмотра и задержка подтверждения сайта.

## 🔐 Приватность

- Расширение не содержит аналитики, телеметрии и удалённого исполняемого кода.
- Настройки и история хранятся локально через `browser.storage.local`.
- Разрешение `storage` используется только для настроек, пресетов и истории.
- Доступ ограничен страницей VACNet на `counter-strike.net` и видео на `replay-video.valve.net`.
- Сетевые обращения нужны для отправки вердикта, загрузки следующего задания, чтения метаданных и воспроизведения Valve WebM.
- Буфер обмена используется только после явного нажатия **«Поделиться клипом»** или **«Копировать метрики»**; расширение ничего из него не читает.
- Данные не отправляются разработчику или сторонним аналитическим сервисам.

> Экспорт истории может содержать прямые URL исходных WebM с параметрами доступа. Не публикуйте JSON-файлы истории и скопированные гостевые ссылки.

Скрытие никнейма меняет только отображаемое имя в верхней панели. Оно не анонимизирует аккаунт, сетевые запросы, ссылки или экспортированные данные.
